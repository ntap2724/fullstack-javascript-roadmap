# Contributing

Contributions start with a task contract and end with a verification report.
Use the templates in [task-contract.md](docs/contributing/task-contract.md)
and [verification-report.md](docs/contributing/verification-report.md).

For agentic tasks, work from an isolated branch or worktree. Keep the diff
within the task contract's allowed files or boundaries, and record the actual
commands, exit results, and evidence before requesting review.

Use the Engineering or Curriculum GitHub issue form to define the work. Pull
requests must complete the evidence checklist, including any unverified areas.
