# Evidence

Store the evidence for each milestone in this directory.

Evidence is how you show that a milestone was actually completed and verified. Keep it honest:
record what you ran and what really happened, including failures you fixed along the way.

## What belongs here

- A short note per milestone describing what you built and how you verified it
- The exact commands you ran and their real results
- Links to the commit, and to a deployment if the milestone required one

## What does not belong here

- Screenshots of code you did not run
- Claims that a command passed when you did not run it
- Secrets of any kind, including tokens, passwords, and connection strings

`implemented` means you wrote the code. `verified` means you ran the declared checks and they
passed. Do not conflate them.
